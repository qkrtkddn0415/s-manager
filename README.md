# 지식 및 일정 관리 시스템 (Task & Knowledge Workspace)

개인 지식 노트와 할 일 및 일정을 태그와 우선순위로 관리하고, 마감일 알림, 대시보드, 다크 모드, 오프라인 지원, 데이터 백업 및 팀 협업을 제공하는 올인원 워크스페이스입니다.

---

## 🌟 주요 기능

1. **대시보드 & 통계**:
   - 업무 진행 현황(전체, 진행 중, 완료율) 및 마감 임박 알림.
   - 우선순위별/카테고리별 태스크 분포 및 최근 지식 노트 빠른 접근.

2. **할 일 & 태스크 관리 (Kanban / List)**:
   - 상태(할 일, 진행 중, 완료) 및 우선순위(긴급, 높음, 보통, 낮음) 지정.
   - 태그 분류 및 필터링, 검색 최적화.
   - 지식 노트(위키)와의 상호 연결 및 팀원 담당자 배정.
   - 팀 실시간 댓글 및 업무 진행 메모.

3. **일정 캘린더 (대한민국 공휴일 & 주말 휴일 표시)**:
   - 월간 캘린더 뷰 및 일자별 마감 일정 시각화.
   - 설날, 추석, 대체공휴일 등 대한민국 법정 공휴일 자동 표기.
   - 일요일(빨간색), 토요일(파란색) 시각 구분 및 상세 일정 팝업.

4. **지식 관리 (위키 / Knowledge Base)**:
   - 마크다운(Markdown) 서식 작성 및 실시간 미리보기.
   - 중요 노트 상단 고정(Pin) 및 태그 분류.

5. **팀 협업 & 멤버 관리**:
   - 워크스페이스 초대 링크 생성 및 역할(관리자, 편집자, 뷰어) 관리.
   - 신규 팀원 초대 및 활동 상태 확인.

6. **데이터 백업 & 오프라인 지원**:
   - JSON 파일 형식으로 전체 데이터 내보내기/가져오기 백업.
   - 로컬 스토리지 자동 영구 동기화로 오프라인 환경에서도 안전하게 사용 가능.

---

## 🛠️ 기술 스택 & 종속성 (Dependencies)

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion (애니메이션), Lucide-React (아이콘), Canvas-Confetti, React-Markdown
- **Backend**: Node.js, Express (REST API 및 파일 기반 데이터베이스)
- **Dev & Build Tool**: Vite, esbuild, tsx

---

## 💾 데이터 저장 및 동기화 구조 (Data Persistence)

본 프로젝트는 오프라인 환경 및 서버 재시작 시에도 데이터가 보존되도록 **이중 지속성(Dual Persistence)** 구조를 채택하고 있습니다.

1. **브라우저 로컬 저장 (`localStorage`)**:
   - 사용자가 할 일 등록/수정, 태그 설정, 체크리스트, 댓글 등을 작성하면 즉시 브라우저에 저장되어 새로고침하거나 네트워크 연결이 끊겨도 데이터가 보존됩니다.
2. **백엔드 영구 파일 스토리지 (`data/store.json`)**:
   - 변경 사항 발생 시 백엔드 동기화 API(`/api/sync`)를 통해 서버 내부 `data/store.json` 파일에 JSON 형태로 영구 기록됩니다.
3. **데이터 백업 및 복원**:
   - UI 상단의 **데이터 백업** 메뉴를 통해 전체 데이터를 언제든지 `.json` 파일로 PC에 다운로드하거나 복원할 수 있습니다.

---

## 🔌 백엔드 API 명세 (Backend REST APIs)

| 메서드 | 엔드포인트 | 설명 |
|---|---|---|
| `GET` | `/api/data` | 저장된 전체 태스크, 지식 노트, 태그, 팀원 데이터 조회 |
| `POST` | `/api/sync` | 클라이언트 변경 사항을 서버 `data/store.json`에 영구 저장 |
| `GET` | `/api/backup` | 전체 데이터를 JSON 백업 파일로 다운로드 스트리밍 |
| `POST` | `/api/restore` | 업로드한 JSON 백업 데이터로 서버 데이터 복원 |
| `POST` | `/api/reset` | 초기 샘플 데모 데이터로 초기화 |
| `GET` | `/api/health` | 서버 헬스체크 및 현재 시각 반환 |

## 🚀 시작하기 & ZIP 파일 실행 가이드 (Local Setup)

> ⚠️ **ZIP 다운로드 시 유의사항**  
> 모던 웹 프로젝트 표준에 따라 용량이 큰 라이브러리 실물 폴더(`node_modules`)는 ZIP 압축 파일 및 Git 저장소에 포함되지 않습니다.  
> 따라서 다운로드 후 **반드시 `npm install`을 실행**하여 종속성을 설치해야 정상 구동됩니다.

### 1. 사전 요구사항
- [Node.js](https://nodejs.org/) v18 이상 설치

### 2. 패키지 종속성 설치
압축을 푼 폴더(또는 Git 클론 폴더)에서 터미널을 열고 다음 명령어를 실행합니다:
```bash
npm install
```
`package.json`에 정의된 React, Express, Vite, Tailwind 등의 모든 의존성 패키지가 자동 다운로드됩니다.

### 3. 개발 서버 실행
```bash
npm run dev
```
터미널 실행 후 브라우저에서 `http://localhost:3000`으로 접속합니다.

### 4. 프로덕션 빌드 및 실행
```bash
npm run build
npm start
```
